# VortexRift-Engine

2.5D Isometric Action-RPG & Real-Time Multiplayer Netcode Engine

---

## Installation

```bash
cd VortexRift-Engine
npm install
```

---

## Build

```bash
npm run build
docker build -t vortexrift-engine:latest .
```

---

## Run

```bash
npm start
docker-compose up -d
```

---

## Dependencies

- **Runtime**: Node.js Standard Library (>= 18.0.0)
- **Architecture**: Modular domain engines with zero external unverified dependencies

---

## Usage

Access the application and endpoints locally on port **3500**.

---

## Testing & Coverage

```bash
npm test
npm run test:coverage
```
